# צפון LIVE – תוכנית, ארכיטקטורה ועלויות

עודכן: 13.11.2026

## 1. ארכיטקטורה

ארבעה חלקים נפרדים שחולקים מסד נתונים אחד:

| חלק | תפקיד | מצב |
|---|---|---|
| ממשק משתמש (`web/`) | פיד, מפה, התראות, ניהול מקורות | נבנה בשלב א |
| שרת API (`app/`) | מגיש נתונים, הרשאות מנהל, בדיקת מקורות | נבנה בשלב א |
| שירות איסוף (`collector/`) | תהליך רציף שמאזין לטלגרם ומושך RSS; כל מקור הוא מתאם (Connector) עצמאי | שלב ב |
| מנוע עיבוד (`processor/`) | סינון רלוונטיות, סיווג, זיהוי מיקום, איחוד כפילויות | שלב ג |

זרימה: מקור → מתאם → `raw_reports` (עם אילוץ ייחודיות שמונע קליטה כפולה) → מנוע עיבוד → `events` + `event_reports` → API → ממשק.

עקרונות:

- **מתאם לכל מקור.** ממשק אחיד: `check()` לבדיקת חיבור ו-`fetch()`/`listen()` לקליטה. הוספת סוג מקור חדש לא נוגעת בשאר המערכת.
- **גיאוגרפיה בטבלה, לא בקוד.** יישובים, כבישים וצמתים הם שורות ב-`locations`. הוספת יישוב בכל הארץ היא הוספת שורה.
- **מיקום רק ממאגר.** מנוע ה-AI יחזיר שם מקום, והמערכת תתאים אותו לשורה ב-`locations`. אם אין התאמה, אין נקודה על המפה. ה-AI לעולם לא מחזיר קואורדינטות.
- **אימות לפי מקורות עצמאיים.** דיווח שסומן כהעתקה (`relation='copy'`) לא נספר כמקור נוסף.
- **ספק AI מתחלף.** קריאה אחת מאחורי ממשק פנימי, עם מפתח במשתנה סביבה.

### סטייה מההעדפות שלך, ולמה

ביקשת React + FastAPI + PostgreSQL. בסביבת העבודה הנוכחית התקנת חבילות חסומה, ולכן שלב א נבנה ממה שמותקן ונבדק בפועל:

| ביקשת | נבנה כרגע | מעבר |
|---|---|---|
| FastAPI | Starlette (הספרייה ש-FastAPI בנוי עליה) | פשוט; אותן פונקציות |
| PostgreSQL | SQLite | כל ה-SQL מרוכז ב-`db.py`/`repo.py`; הסכמה תואמת |
| React + TypeScript + Tailwind | HTML/CSS/JavaScript ללא שלב בנייה | דורש כתיבה מחדש של `web/` |

המלצה: לעבור ל-PostgreSQL ול-FastAPI בתחילת שלב ב, כשההתקנות יהיו פתוחות. לגבי React: הממשק הנוכחי קטן ועובד; כדאי לעבור כשמסך ניהול הדיווחים (סעיף 13) ייכנס, כי שם המורכבות גדלה.

## 2. מגבלות החיבור לטלגרם

- **Bot API לא מתאים.** בוט מקבל הודעות מערוץ רק אם צורף אליו (בפועל כמנהל). אי אפשר לצרף בוט לערוצים של אחרים.
- **הדרך שעובדת: MTProto עם חשבון משתמש, באמצעות Telethon.** חשבון משתמש רגיל יכול לקרוא כל ערוץ ציבורי ולקבל הודעות חדשות ועריכות בזמן אמת.
- **מה נדרש ממך:** מספר טלפון לחשבון טלגרם ייעודי (מומלץ מספר נפרד, לא האישי), ורישום אפליקציה ב-my.telegram.org לקבלת `api_id` ו-`api_hash`. ההתחברות הראשונה דורשת קוד חד-פעמי שמגיע לטלגרם, ואתה מזין אותו ישירות בשרת, לא בצ'אט.
- **קובץ ה-Session שווה ערך לסיסמה.** נשמר רק בשרת, מחוץ ל-Git.
- **מגבלות קצב.** טלגרם מחזירה `FLOOD_WAIT` כשמבקשים יותר מדי. השירות יכבד את ההמתנה, יצטרף לערוצים בהדרגה ויקרא בלבד.
- **סיכון:** טלגרם עשויה להגביל חשבון שנראה אוטומטי. זו הסיבה לחשבון ייעודי ולקריאה בלבד. אין דרך לבטל את הסיכון לגמרי.
- **ערוצים פרטיים** (קישורי הזמנה) לא נתמכים, והמערכת דוחה אותם כבר בהזנה.

## 3. האם Claude Code יכול לבנות את זה בסביבה שלך

כן לכתיבת הקוד ולבדיקות, עם שלוש מגבלות בסביבה הנוכחית:

1. **אין התקנת חבילות.** לכן אין כרגע FastAPI, Telethon או React. אפשר לפתוח זאת בהגדרות הרשת של החשבון; צ'אט חדש יקלוט את השינוי.
2. **אין חשבון GitHub מקושר.** הקוד נמסר כקובץ ZIP ואינו נשמר במאגר. קישור GitHub יאפשר לי לשמור ולהמשיך מאותה נקודה בכל שיחה.
3. **אין הרצה רציפה.** סביבת העבודה נעצרת בין הודעות, ולכן שירות האיסוף חייב לרוץ על שרת משלך.

## 4. אירוח

**שרת וירטואלי קטן אחד (VPS)** שמריץ את ארבעת החלקים. זה הפתרון הפשוט והזול לתהליך שחייב חיבור קבוע לטלגרם; שירותי "serverless" לא מתאימים לחיבור מתמשך.

מחירים שנבדקו בנובמבר 2026 (משתנים, יש לאמת לפני הזמנה):

- Hetzner CX23: כ-5.99 אירו לחודש כולל IPv4, לאחר שתי העלאות מחיר ב-2026. מאז יוני יש הגבלות על פתיחת שרתים חדשים.
- OVHcloud VPS-1 (2 ליבות, 4GB): כ-4.49 אירו לחודש.

שרת של 2GB–4GB זיכרון מספיק לגרסה ראשונה.

## 5. עלויות צפויות לגרסה ראשונה קטנה

| רכיב | עלות חודשית משוערת |
|---|---|
| שרת VPS | 5–7 אירו |
| מודל שפה (Claude Haiku 5.5: 0.10$ למיליון טוקנים קלט, 0.50$ פלט) | 3–10$ |
| טלגרם (API) | חינם |
| מפות OpenStreetMap | חינם בנפח קטן (יש מדיניות שימוש הוגן) |
| דומיין (לא חובה בהתחלה) | כ-1$ (10–15$ לשנה) |
| כרטיס SIM לחשבון טלגרם ייעודי | חד-פעמי / זול |
| **סה"כ** | **כ-10–20$ לחודש** |

חישוב ה-AI: 15 מקורות × כ-100 הודעות ביום × כ-1,000 טוקנים להודעה ≈ 1.5 מיליון טוקנים ביום. סינון מוקדם לפי מילות מפתח (לפני ה-AI) יוריד את זה משמעותית.
