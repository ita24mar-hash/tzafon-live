# צפון LIVE

מערכת מידע אזורי לצפון ישראל. התוכנית המלאה: `docs/PLAN.md`.

## ניסוי האיסוף (ללא שרת, ללא תשלום)

GitHub Actions מריץ כל 15 דקות את `collector/run.py`, שעושה ארבעה דברים:

1. קורא את דף התצוגה הציבורי (`t.me/s/...`) של כל ערוץ פעיל ב-`collector/sources.json`.
2. מוסיף הודעות חדשות ליומן הקבוע `data/raw_reports.jsonl` ושומר אותו במאגר (כך שום דבר לא נעלם בין הרצות).
3. בונה אתר סטטי עם ההודעות ומפרסם אותו ב-GitHub Pages.
4. מסמן את ההרצה ככושלת אם מקור לא נקרא, ומציג את השגיאה בלשונית "מקורות".

באתר הניסוי אין נתוני הדגמה. לשונית "אירועים מנותחים" ריקה עד שיתווסף ניתוח ה-AI.

הפעלת ערוץ נוסף: לשנות `"enabled": false` ל-`true` ב-`collector/sources.json`.

מגבלות: זה אינו API רשמי של טלגרם, מבנה הדף עלול להשתנות, והעדכון מגיע באיחור. זו אינה מערכת התרעה.

## גרסת השרת (שלב א)

בהרצה מקומית עם שרת מוצגים **נתוני הדגמה מסומנים**, אלא אם מגדירים `SEED_DEMO=0`.

## הפעלה במחשב

נדרש Python 3.11 ומעלה.

```bash
pip install -r requirements.txt
cp .env.example .env        # ואז לערוך את ADMIN_TOKEN למחרוזת אקראית ארוכה
export $(grep -v '^#' .env | xargs)
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --no-access-log
```

לפתוח בדפדפן: http://localhost:8000
מהטלפון באותה רשת Wi-Fi: `http://<כתובת-המחשב>:8000`

`--no-access-log` מונע רישום של פרמטרי הסינון (כולל מיקום משוער) בלוג השרת.

## בדיקות

```bash
python -m pytest -q
```

## מבנה

```

app/net.py       גישה בטוחה לכתובות חיצוניות (SSRF) ובדיקת RSS

app/main.py      נקודות הקצה של ה-API, הרשאות, הגבלת קצב
app/telegram_web.py  מתאם לדף התצוגה הציבורי של ערוץ טלגרם
app/ingest.py    קליטת הודעות, מניעת כפילות, יומן קבוע
collector/       הרצת האיסוף ובניית האתר הסטטי; רשימת המקורות
data/            יומן ההודעות שנקלטו (נכתב אוטומטית)
.github/workflows/collect.yml  התזמון ב-GitHub Actions
web/             ממשק המשתמש
tests/           בדיקות אוטומטיות
```

## ממשק הניהול

לשונית "ניהול" דורשת את `ADMIN_TOKEN`. בלי ערך של 16 תווים לפחות, הממשק כבוי.
מצבי מקור: **הוגדר** (רק נשמר) ← **החיבור נבדק** (בדיקה הצליחה בפועל) ← **קולט מידע אמיתי** (נקלטה לפחות הודעה אחת).

## הסרת נתוני ההדגמה

להגדיר `SEED_DEMO=0` ולמחוק את קובץ המסד (`data/tzafon.db`) לפני הפעלה מחדש.

## ידוע וחסר

- ספריית המפה (Leaflet) נטענת מ-unpkg.com. לפני עלייה לאוויר יש לאחסן אותה מקומית.
- הגבלת הקצב נשמרת בזיכרון ומניחה גישה ישירה; מאחורי פרוקסי יש להגדיר כותרת IP מהימנה.
- טבלאות `users` ו-`alert_preferences` קיימות אך עדיין לא בשימוש; התראות נשמרות במכשיר.
